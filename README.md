# Text Sorter (Onegin Sorter)

## Описание проекта
Это консольное приложение на C++, которое читает текстовый файл, разбивает его на строки и выполняет сортировку строк. Сортировка может производиться как с начала строки, так и с конца. При сравнении игнорируются знаки препинания, пробелы и регистр символов.

Программа позволяет выводить результаты в терминал и/или записывать их в отдельные файлы.

## Структура проекта
Проект разделен на несколько модулей для удобства поддержки:

*   **`main.cpp`** — точка входа в программу. Управляет порядком выполнения задач: чтение файла, сортировка, вывод и запись результатов.
*   **`read_file.cpp` / `read_file.h`** — отвечает за чтение файла, обработку символов переноса строк (`\r\n` заменяются на `\0`), создание массива указателей на строки, а также за разбор аргументов командной строки (`getopt`).
*   **`comparators.cpp` / `comparators.h`** — содержит функции сравнения для `qsort`:
    *   `CompareStrStart` — сортировка строк с начала.
    *   `CompareStrEnd` — сортировка строк с конца.
*   **`other.cpp` / `other.h`** — вспомогательные функции: вывод текста (`PrintText`), запись в файл (`WriteToFile`), копирование массива строк (`Selfstrdup`), генерация имен файлов (`CreateNameFile`) и вывод справки (`PrintHelp`).
*   **`common.cpp` / `common.h`** — обертки для безопасного выделения памяти (`safe_malloc`, `safe_calloc`, `safe_free`) и макросы для проверок/предупреждений (`yaissert`, `warning`).

Проект организован в виде двух основных папок для исходного кода и корневых файлов конфигурации и примеров:

## Сборка
Для сборки проекта вам понадобится компилятор с поддержкой C++ (например, `g++`). Выполните следующую команду в терминале:

```bash
git clone https://github.com/Knightususa/Onegin.git
cd Onegin
g++ ./Source/other.cpp ./Source/read_file.cpp ./Source/common.cpp ./Source/main.cpp ./Source/comparators.cpp  -DNDEBUG -o main.exe  
```
## Запуск программы и аргументы

### Описание
Программа читает текст из файла и сортирует его по началу или концу строки. Она может выводить первые n строк в терминал, а также записывать отсортированный текст в файлы.

### Флаги (Аргументы командной строки)
*   `-f [STRING]` — Введите имя файла (без расширения), из которого будет прочитан текст.
*   `-n [INT]` — Введите количество первых строк файла (или всех файлов сразу) для вывода в терминал (по умолчанию 100).
*   `-p [STRING]` — Введите, какие тексты выводить в терминал:
    *   `r` — исходный текст (raw text)
    *   `s` — текст, отсортированный по началу строки
    *   `e` — текст, отсортированный по концу строки
*   `-w [STRING]` — Введите, какие тексты записывать в файл:
    *   `r` — исходный текст (raw text)
    *   `s` — текст, отсортированный по началу строки
    *   `e` — текст, отсортированный по концу строки

### Примеры запуска

### 1. Вывод исходного текста в консоль

```bash
.\main.exe -f Onegin_text -p r -n 100
```

Что происходит:

- читается файл `Onegin_text.txt`;
- в терминал выводятся первые 100 строк исходного текста;
- сортировки не выводятся;
- файлы не создаются.

### 2. Вывод 10 строк, отсортированных по началу строки

```bash
.\main.exe -f Onegin_text -n 10 -p s
```

Что происходит:

- читается файл `Onegin_text.txt`;
- выполняется сортировка строк с начала;
- в терминал выводятся первые 10 строк уже отсортированного текста;
- в файлы ничего не записывается.

### 3. Запись сортировок по началу и по концу строки в файлы

```bash
.\main.exe -f Onegin_text -w se
```

Что происходит:

- читается файл `Onegin_text.txt`;
- создаются файлы:
  - `s` — текст, отсортированный по началу строки;
  - `e` — текст, отсортированный по концу строки;
- в терминал ничего не выводится, потому что не указан `-p`;
- в файлы попадает весь текст, а не только первые `n` строк, потому что `-n` влияет только на вывод в терминал.

### 4. Комбинированный пример

```bash
.\main.exe -f Onegin_text -n 10 -p re -w es
```

Что происходит:

- `-f Onegin_text` — читается файл `Onegin_text.txt`;
- `-n 10` — в терминал выводятся первые 10 строк для выбранных режимов;
- `-p re` — в терминал выводятся:
  - `r` — исходный текст;
  - `e` — текст, отсортированный по концу строки;
- `-w es` — в файлы записываются:
  - `e` — текст, отсортированный по концу строки;
  - `s` — текст, отсортированный по началу строки;
- сортировка по началу (`s`) не выводится в терминал, потому что её нет в `-p`;
- исходный текст (`r`) не записывается в файл, потому что его нет в `-w`;
- `-n 10` не ограничивает запись в файлы: в файлы попадает весь текст.

### 5. Вывод и запись всех вариантов сразу

```bash
.\main.exe -f Onegin_text -n 5 -p rse -w rse
```

Что происходит:

- читается файл `Onegin_text.txt`;
- в терминал выводятся первые 5 строк для трёх вариантов:
  - `r` — исходный текст;
  - `s` — сортировка по началу;
  - `e` — сортировка по концу;
- в файлы записываются все три варианта: `r`, `s`, `e`;
- `-n 5` ограничивает только вывод в терминал, а в файлы по-прежнему пишется весь текст.
